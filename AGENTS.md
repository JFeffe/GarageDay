# Travail sur Garage Day

- Après chaque modification demandée, effectuer les vérifications adaptées, créer un commit et pousser les changements sur GitHub. L’utilisateur a explicitement demandé de garder le dépôt distant à jour.
- Conserver le multijoueur Web ; l’accueil local donne accès au navigateur.
- Pour les changements de jeu ou de menus, lancer les suites `test_workshop.gd` et `test_game_menu.gd` avec Godot 4.5.1. Pour la liaison du menu Web, lancer `node test_lobby.cjs`.
